## 功能概览

- 🏆 多维度排行榜（本地模型 / 云端模型 × 文字 / 生图 / 生视频）
- 👤 Linux DO OAuth 登录（接入信任等级体系，≥ 1 级即可投票/评论）

- 📈 贝叶斯加权均分排序，避免少票模型霸榜
- 📊 个人偏好权重：每个用户可自定义维度权重，看到不同的"个人排行"
- 💬 站内评论：Markdown / 二级回复 / 点赞点踩 / 举报
- 📢 公告系统：管理员发布通知，置顶横条 + 历史列表
- 🆕 观察区：新模型先在观察区接受投票，满足条件（7 天 或 50 票）自动晋升
- 📱 移动端卡片视图自适应
- 👥 个人中心：查看自己的评分与评论历史

## 评分排序算法

展示给用户看的是真实算术均分，排行用**贝叶斯加权均分**计算，避免少票模型霸榜：

```
weighted = (C × m + n × avg) / (C + n)
```

其中：
- `n` = 该 (model, dimension) 的有效投票数
- `avg` = 该 (model, dimension) 的算术均分
- `m` = 该 dimension 的全站均值
- `C` = 平滑系数（当前为 30）

热度排序公式（用于评论）：

```
hotScore = (likes - dislikes) - hours_since_post / 4
```

## 评分时间衰减

模型迭代很快，3-6 个月前的"9 分"和今天的"9 分"含义已经不同。
为避免老模型一旦拿满分就永远霸榜，每张评分会随时间衰减权重：

```
weight = max(0.5 ^ (age_days / 90), 0.2)
```

| 票龄 | 权重 |
|------|------|
| 当天 | 100% |
| 1 个月 | 79% |
| 3 个月（半衰期） | 50% |
| 6 个月 | 25% |
| 9 个月及以后 | 20%（保底，永不归零） |

排行用的是**加权后的票数和均分**：

```
effectiveN  = Σ weight
weightedAvg = Σ (score × weight) / effectiveN
```

然后再套到上面的贝叶斯公式里。

**对用户的提示：**
- 个人中心里每张评分显示新鲜度进度条
- 权重低于 60% 时变红色 + 显示"重新评估"按钮
- 顶部黄色卡片告知有多少张评分待更新

**重投不需要回头改：** 直接对同一维度重新打分即可，时间戳会刷新。如果同一模型的新发布版本让你想重新评估，鼓励直接更新当前评分。
